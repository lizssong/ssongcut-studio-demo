# 쏭컷 AI STUDIO (BETA)

긴 영상 하나를 올리면 AI가 이야기를 요약하고, 핵심 장면을 골라, 자막을 입힌 9:16 숏츠 여러 편을 자동으로 만듭니다.

## 흐름
1. 소리 추출 (브라우저)
2. 받아쓰기: Gemini(오디오만 전송, 75초 단위 병렬) 또는 내 PC Whisper(키 없이)
3. 요약 · 하이라이트 선택 · 제목 생성 (Gemini, 키 없으면 브라우저 기본 분석)
4. 세로 화면 구성(블러 배경/꽉 채우기) + 단어 강조 자막 + 제목 + 채널명
5. MP4 저장: WebCodecs로 원본을 직접 디코드해 H.264+AAC 1080x1920 30fps로 인코딩 (영상·소리 싱크 고정)

## 사용
- GitHub Pages 등 https 주소에 index.html 한 파일만 올리면 동작
- Gemini 키: https://aistudio.google.com/apikey 에서 무료 발급, 브라우저 localStorage에만 저장
- PC 크롬/엣지 권장

## 확인한 결과 (2026-10-30)
- 9분 47초 강의 영상 → 약 30~60초 만에 숏츠 5~6편 + 요약
- 59.6초 숏츠 출력: 1080x1920, 30fps(1,788프레임), 영상 59.605초 = 소리 59.605초
