# 쏭컷 스튜디오 · 무료 기술 데모

브라우저에서 실행되는 영상 편집 프로토타입입니다. 외부 라이브러리 없이 HTML 한 파일로 구성됩니다.

- 로컬 영상 트림, 3가지 화면 비율, 제목 및 SRT 자막 합성
- 지원 브라우저에서 MP4 또는 WebM 내보내기
- 원본 영상은 서버로 전송되지 않음
- AI, 로그인, 결제, 클라우드 저장 없음

Chrome 데스크톱 권장. 최대 500MB 입력, 0.3~180초 구간 내보내기. 실시간 캡처라 길이에 수백 밀리초 이상 차이가 날 수 있습니다. 영상 처리 중 탭을 유지하세요.

GitHub Pages의 프로젝트 데모 용도로 공개합니다. 상용 서비스 운영·결제·판매는 하지 않습니다. 호스팅 제공자는 접속 로그를 처리할 수 있습니다. 권리가 있는 영상만 사용하세요.
