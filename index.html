A LITTLE GUIDE

첫 번째 숏폼, 이렇게 만들어요.

3단계로 완성하기

  1. 영상 불러오기: 내 영상 선택 또는 8초짜리 자체 제작 샘플 체험을 누릅니다.
  2. 편집: 시작·종료 시간을 원본 기준 초로 설정하고 비율, 제목, 자막을 조정합니다.
  3. 저장: 내보내기를 누르고 처리가 끝나면 다운로드합니다. 편집 길이만큼 시간이 걸립니다.

알아두세요

출력은 720p/1080p를 선택할 수 있지만 원본보다 화질이 좋아지지는 않습니다. MOV는 코덱에 따라 재생되지 않을 수 있습니다. 재생되지 않으면 MP4(H.264/AAC)로 변환한 원본을 사용하세요.

실시간 녹화 방식이라 선택 길이와 출력 길이에 수백 밀리초 이상의 차이가 생길 수 있으며, 프레임 단위 정밀 편집용이 아닙니다. MP4는 브라우저 인코더가 지원할 때만 표시합니다. 지원하지 않거나 실패하면 WebM으로 저장하세요. 플랫폼별로 WebM 업로드 지원이 다릅니다.

타임드 자막이 없는 구간에는 기본 하단 자막이 표시됩니다. 자막을 너무 길게 쓰면 미리보기에서 최대 3줄까지만 표시되므로 짧게 나눠주세요. SRT 시간은 원본 기준입니다. 편집본에 맞춘 SRT는 선택한 구간 기준으로 이동해 저장됩니다.

작업 설정은 자동 저장되지 않습니다. '편집 설정 저장'으로 JSON 파일을 저장하세요. 원본은 포함되지 않으며, 새로 열 때 원본 영상을 다시 선택해야 합니다.

현재 제공하지 않는 기능

AI 영상 생성, 음성 인식, 하이라이트 내용 분석, 화자 추적, 유튜브 링크 다운로드, 클라우드 저장, 로그인, 결제는 아직 없습니다. 단순 시간 분할을 AI로 표시하지 않습니다.

개인정보와 저작권

이 버전은 외부 폰트·분석 스크립트·API를 사용하지 않습니다. 영상은 브라우저 메모리에서 처리하며 서버로 보내지 않습니다. 브라우저나 기기의 다운로드 기록과 파일은 사용자가 관리하세요. 업로드·편집·발행할 권리가 있는 파일만 이용하세요.

무료 기술 데모이며 회원가입·결제·서버 업로드를 제공하지 않습니다. 이 페이지는 GitHub Pages에서 제공되며 호스팅 제공자는 접속 로그를 처리할 수 있습니다. 유료 상용 서비스는 별도 호스팅과 운영 정책을 갖춘 뒤 출시해야 합니다.
